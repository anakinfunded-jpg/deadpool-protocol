# Deadpool — Project Rules

## Memory Enforcement (MANDATORY)
After completing ANY task or set of changes:
1. Update the project auto-memory file (`MEMORY.md` in the `.claude/projects/D--deadpool/memory/` directory) to reflect what was done
2. Record: what changed, which files were modified, any new patterns or decisions made
3. Keep the memory concise but complete — future sessions must know exactly where we left off
4. If a new topic area emerges (e.g., deployment, testing), create a dedicated file in the memory directory and link it from MEMORY.md

This rule applies to ALL work: features, bugfixes, refactors, config changes, anything.
